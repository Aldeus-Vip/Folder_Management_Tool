① Excelを取り込む

FolderTreeExporter で出力した Excel(.xlsx)を読み込み、DB(.db)に変換します。
Excelで並べ替え・保存し直したファイルも取り込めます(「フルパス」列から階層を復元します)。

Excelファイル 保存するDB名

② フォルダをスキャンする

フォルダを直接走査してDBを作ります(Excelを経由しないので高速です)。
ネットワークドライブは「同時読み込み数」を増やすと速くなることがあります。

対象フォルダ 保存するDB名 同時読み込み数

③ 保存済みのDBを開く

DBファイル

④ 複数のDBを統合する(マージ)

部署ごと・ドライブごとにスキャン/取込したDBを、フルパスを基準に1つのツリーへ統合した新しいDBを作ります(元のDBは変更しません)。
・共通の親フォルダがあればそれがルートになります。無い場合(別サーバー・別ドライブ)は「(統合ルート)」の下に並べます。
・同じパスが複数のDBにあるときは、下の「優先」の設定に従って1つを採用します。アクション・担当・メモも同じ順で引き継ぎます。
