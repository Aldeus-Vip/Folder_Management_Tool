① フォルダをスキャンする

フォルダ配下のすべてのフォルダ・ファイルを読み込み、DB(.db)を作ります。
ネットワークドライブは「同時読み込み数」を増やすと速くなることがあります。

対象フォルダ 記録するパス(任意) SharePoint を OneDrive で同期(ショートカット)したフォルダをスキャンする場合に、SharePoint の URL を入れます。 DBには個人のパス(C:\Users\…)ではなくこのURLで記録され、全員が同じパスで作業・統合できます。実際の場所はPCごとに「⚙ オプション」で設定します。 保存するDB名 同時読み込み数

② 複数のDBを統合する(ツリーのマージ)

部署ごと・ドライブごとにスキャンしたDBを、フルパスを基準に1つのツリーへ統合した新しいDBを作ります(元のDBは変更しません)。
・共通の親フォルダがあればそれがルートになります。無い場合(別サーバー・別ドライブ)は「(統合ルート)」の下に並べます。
・同じパスが複数のDBにあるときは、下の「優先」の設定に従って1つを採用します。整理後のフォルダ構成・アクション・タグも同じ順で引き継ぎます。
・複数人で編集したアクションをまとめる場合は「ファイル」→「アクションの統合(Merge)」を使ってください。
