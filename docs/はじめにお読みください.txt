==============================================================
 FolderManager(フォルダ整理・5S支援ツール) はじめにお読みください
==============================================================

■ 起動と終了
  ・FolderManager.exe をダブルクリック → ブラウザで画面が開きます
  ・初回に「WindowsによってPCが保護されました」と出たら
    「詳細情報」→「実行」を押してください
  ・終了: 画面右上の「⏻ 終了」(タブを閉じても数分で自動終了します)
  ・データ(DB)は exe と同じ場所の projects フォルダに保存されます

■ 作業の流れ(担当者)
  1. 管理者から受け取ったマスターDBを開く
       「ファイル」→「開く」(共有フォルダのマスター .db を選択)
  2. 作業用コピーを作る
       「ファイル」→「作業用コピーを作成」→ 作業者コード(部署名・氏名など)を入力
       ※ 自分のPCに保存されます。以降はこのコピーを編集します
  3. 「整理」画面で自分の範囲を表示する
       上部の「担当」で自分の部・課・担当者を選ぶ
  4. 左の「現在のフォルダ構成」の項目を右クリックしてアクションを決める
       ・移動…  : 右の「整理後のフォルダ構成」で移動先をクリック
                  (移動後の名前・期限・タグも設定できます)
       ・削除    : 整理後には残さない
       ・保留    : 判断を後回しにする(「表示: 保留のみ」で後から確認)
     ※ フォルダに設定すると、中身すべてに同じアクションが及びます
  5. 終わったら「ファイル」→「アクションの統合(Merge)」
       統合先「元のマスターへ統合する」を選んで「比較する」→「マスターへ統合する」
       ※ 他の人と同じ項目を違う内容にしていた場合は、採用する方を選びます

■ 便利な操作
  ・ダブルクリック          : ファイルを既定のアプリで開く(中身の確認)
  ・ドラッグ&ドロップ      : 左の項目を右の仮想フォルダへ移動
  ・キー                    : Del=削除 / M=移動 / H=保留 / Backspace=解除
  ・左右の境目              : ドラッグで幅を調整
  ・「⛔ 5S外れ」           : 整理ルールに合わない項目。移動・名前変更で直すと消えます
  ・「アクション設定済みを非表示」: 残り(未処理)だけを表示

■ 色の意味(整理画面)
  ・赤い行         : SharePoint に移行できない名前・長すぎるパス・アクセス不可
  ・黄色い行       : 階層が深い
  ・取り消し線     : 削除を設定済み
  ・紫の文字       : 保留
  ・行の左の赤線   : 5Sルールに合わない
  ・🔒             : スキャン時にアクセスできなかったフォルダ(サイズ不明)

■ 注意
  ・マスターDBを直接編集しないでください(必ず作業用コピーで作業)
  ・このツールは実際のファイルを移動・削除しません。
    実際の整理は管理者が「アクション一覧」→ PowerShell スクリプトで行います
  ・困ったときは、画面のスクリーンショットを添えて管理者に連絡してください

  問い合わせ先: (担当者名・連絡先を記入)
