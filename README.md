# FolderManager(フォルダ整理・5S支援ツール)

大規模ファイルサーバーのフォルダ構成を **SQLite(.db)** に取り込み、ブラウザ画面で
「どのファイル/フォルダを、整理後のどこへ置くか(または削除するか)」を決めていく Windows 用ツールです。
数十万〜100万項目でも軽快に動作します。

- インストール不要の **単一exe**(Python・Office 不要)。起動するとブラウザで画面が開きます(黒いウィンドウは出ません)
- PC内だけで動作し、外部には通信しません
- 終了: 画面右上の「⏻ 終了」、またはブラウザのタブを閉じると自動で終了します

## 使い方の流れ

1. **データ取り込み** → 「① フォルダをスキャンする」で対象フォルダを読み込み、DBを作る
2. **整理** 画面で、左の「現在のフォルダ構成」の各項目にアクションを決める
   - **🗑 削除**: 整理後には残さない(左のツリーで取り消し線・グレー表示)
   - **📦 移動**: 右の「整理後のフォルダ構成(仮想)」のどこへ置くかを決める。**名前変更**・**期限**も設定可
   - フォルダに設定すると配下すべてに及びます(配下に個別の設定があればそちらを優先)
3. 右の仮想ツリーに、整理後の構成ができあがっていく様子が表示されます
4. **アクション一覧** から CSV や、実際に移動・削除する PowerShell スクリプトを出力

### 整理画面の操作(右クリックメニュー)

| 場所 | 右クリックメニュー |
|---|---|
| 左(現在のフォルダ構成) | 移動… / 削除 / 解除(設定がある場合のみ) / タグ・メモの編集 / 配下を検索 / 配下の重複候補 / ファイルを開く / プロパティ |
| 右(整理後のフォルダ構成)の仮想フォルダ | 名前の変更 / 移動… / 削除 / 新規フォルダ(直下) / メモの編集 / プロパティ |
| 右に配置した項目 | 名前の変更(移動後の名前) / 移動… / 解除 / 新規フォルダ(同じ階層) / タグ・メモの編集 / ファイルを開く / ツリーへ移動 / プロパティ |
| 右の空白部分 | 新規フォルダ(ルート直下) |
| 検索・リスト / アクション一覧 | 配下を検索 / 配下の重複候補 / ツリーへ移動 / ファイルを開く / プロパティ / タグ・メモの編集 |

- **移動…**: ウィンドウで「期限(永続 / 日付)」と「タグ」を設定 → OK → 画面上部に黄色の帯が出るので、右のツリーから移動先の仮想フォルダ(🗂)をクリック。キャンセル(Esc)するまで、他の操作はできません
- **ドラッグ&ドロップ**: 左の項目(複数可)を右の仮想フォルダへ。仮想フォルダ同士も可
- **キー**: Del=削除 / M=移動… / Backspace=解除 / F2=名前の変更(右) / ダブルクリック・Enter=ファイルを開く
- **アクション設定済みを非表示**: チェックすると残り(未処理)だけを表示。上部のバーとゲージで進み具合を確認
- **アクセスできなかったフォルダ**: 🔒と赤色で表示し、サイズ・件数は「不明」。プロパティにエラー内容(アクセス拒否など)を表示

## 整理後の構成ルール(5S)

「⚙ オプション」→「整理後の構成ルール(5S)」で、仮想ツリーに課すルールを設定します。
各ルールは **禁止**(その操作はできない)/ **警告のみ** / **無効** を選べます。

| ルール | 既定 |
|---|---|
| 最大階層(仮想ルート=0) | 6・禁止 |
| 整理後のフルパス文字数の上限(「整理後のルートの実際の場所」を含む) | 250・禁止 |
| 1フォルダ直下の項目数の上限 | 100・警告 |
| 禁止文字・末尾の「.」や空白・予約語(名前変更で直せる) | 禁止 |
| コピー・版管理的な名前(「- コピー」「(1)」「旧」「v2」等) | 警告 |
| タグが無い項目の移動 | 無効 |

また、**同じ階層に似た名前のフォルダ**(表記ゆれ・一方を含む・よく似た名前。年度など数字だけの違いは除く)があると ⚠ で警告します。

## 複数人での作業(1人でも同じ流れ)

DBファイルは共同編集に向かないため、次の運用で作業をまとめます。

1. マスターDB(作業者コードなし)を **共有フォルダ** に置く
2. 各自が「ファイル」→「**作業用コピーを作成**」で、**作業者コード**(部署名・氏名など。日本語可)付きのコピーを **自分のPC** に作って編集する
   - コピーには元のマスターの場所が記録されます
   - マスターのままアクションを設定しようとすると、作業者コードの入力を求められます
3. 「ファイル」→「**アクションの統合(Merge)**」(開いている作業用コピーは自動で追加されます。**1人分だけでも可**)
   - 統合先「**元のマスターへ統合する**」: マスターを直接更新し、元のマスターは `_backup_日時.db` として残します
   - 他の人の統合でマスターが先に更新されていても、マスターの現在の内容と比較して統合できます
   - 同じ項目を異なる内容に変えていた場合(マスター側を含む)は **競合** として並べて表示し、採用する方を選ぶ
   - 「統合後、作業用コピーを新しいマスターから作り直して作業を続ける」で、そのまま作業を再開できます
4. 他の人は、更新されたマスターから作業用コピーを作り直して作業を続けます

## SharePoint のフォルダを扱う場合

プログラムから SharePoint の URL へ直接アクセスすることはできないため、**OneDrive の同期(「OneDrive へのショートカットを追加」または「同期」)** でPCに同期したフォルダをスキャンします。

- スキャン時に「**記録するパス**」へ SharePoint の URL を入れると、DBには個人のローカルパス(`C:\Users\個人名\OneDrive - 会社\…`)ではなく **URL で記録** されます。全員が同じパスで作業・統合できます
- ファイルを開く・実行スクリプトでは「⚙ オプション」→「**このPCでの実際の場所**」(PCごとの設定)に読み替えます
- スキャン済みのDBも、「⚙ オプション」→「記録用のパス」で後から設定・変更できます
- 同期フォルダ内の「オンラインのみ」のファイルも、一覧・サイズは取得できます(開く・内容比較の際はダウンロードされます)

## その他の機能

| 画面 | 内容 |
|---|---|
| データ取り込み | ① フォルダスキャン(並列読み込み)/ ② 複数DBの統合(ツリーのマージ。整理計画も引き継ぎ) |
| ファイル メニュー | 開く / 最近開いたファイル / 作業用コピーを作成 / 作業者コードを設定 / アクションの統合 / 閉じる |
| サマリー(5S) | 進み具合、5Sチェック(古い・重複・一時ファイル・空フォルダ・コピー名・深い階層・移行警告など)、容量・更新年数・階層の分布 |
| 検索・リスト | 名前・拡張子・警告・処理状況(未処理/処理済み/削除/移動)・タグ等で絞り込み、結果への一括操作、CSV出力 |
| 重複候補 | 同名・同サイズのファイル。SHA-256で内容比較、「最新以外を削除」 |
| アクション一覧 | 設定したアクションの一覧、CSV / PowerShell実行スクリプト(既定はドライラン)出力 |
| ⚙ オプション | テーマ(自動/ライト/ダーク)、開いているDBの情報、判定の閾値、整理後の構成ルール |

## 注意事項

- 生成される PowerShell スクリプトは既定でドライラン(何も変更しない)です。`-Execute` を付けると実行します。「削除」は完全削除です。
- 重複候補は「ファイル名+サイズ」による簡易判定です。
- 目安: 約77万項目のスキャン結果DBで、整理画面の操作は1秒未満(未処理の検索は約1秒)。

## 開発者向け

```
go test ./...                                              # テスト
FM_BIG=1 go test ./internal/fsdb -run TestBigPlan -v       # 約77万項目での性能確認
GOOS=windows GOARCH=amd64 go build -trimpath -ldflags "-s -w -H windowsgui" -o dist/FolderManager.exe ./cmd/foldermanager
```

| パス | 内容 |
|---|---|
| `cmd/foldermanager` | 起動処理(ローカルHTTPサーバー起動・ブラウザ表示・自動終了) |
| `internal/ingest` | フォルダスキャン・DB(ツリー)統合 |
| `internal/fsdb` | DB構築・検索・整理計画(アクション/仮想フォルダ/タグ/5Sルール)・複数人の統合・出力 |
| `internal/osutil` | Windowsのファイル/フォルダ選択ダイアログ(エクスプローラー形式)など |
| `internal/server` | JSON API と画面(`web/`) |

起動オプション: `FolderManager.exe [-port 8765] [-projects フォルダ] [-idle 3m] [-no-browser] [開くDB]`
